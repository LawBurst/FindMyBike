# FindMyBike hosted website

Static site prepared from the user-provided FindMyBike_OFFLINE.html.

## Deployment
1. Create a GitHub repository named `FindMyBike`.
2. Upload `index.html` and the entire `images` folder to the repository root.
3. On Vercel, choose Add New > Project > Import the FindMyBike repository.
4. Framework Preset: Other. Root directory: `./`. No build command or environment variables. Deploy.
5. Future pushes to GitHub `main` automatically trigger Vercel deployments.

This site contains 42 locally hosted model photos. Four missing photos still use third-party links or placeholders.
The app is static and needs no database, API keys, or backend.
